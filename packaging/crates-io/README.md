# chat-cli

Your chats, in the terminal — a fast, keyboard-first TUI inbox for WhatsApp and Slack.

Install the prebuilt binary with [`cargo-binstall`](https://github.com/cargo-bins/cargo-binstall):

```bash
cargo binstall chat-cli
```

Or download a binary directly from the
[releases page](https://github.com/bogdanr/chat-cli/releases).

> This crates.io package is a lightweight stub that provides `cargo binstall`
> metadata. The application itself is distributed as prebuilt binaries on
> GitHub. Source: <https://github.com/bogdanr/chat-cli>
